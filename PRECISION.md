# Precision diagnostics

Download and extract [precision_sensitivity.zip](precision_sensitivity.zip), then open analysis_clean/precision_sensitivity/precision_report.html. Contains data without review text/names, code, all 144 specifications, independent verification, and the plot.

Holding four-week windows and equal restaurant weights fixed, finer 5/10/20 km location controls reduce overlap and worsen WPME-ME precision. Earlier history adds little precision. Baseline rating/activity adjustment reduces non-Trump standard errors by about 28–29%, but moves estimates toward zero: election +0.020 (p=.531), ban -0.013 (p=.654). Baseline adjustment changes the identifying assumption; these are exploratory sensitivity checks, not established causal effects. County clustering remains fixed. All three pairs, both events and county types are reported.

The spatial models have county-FE comparators on exactly the same restaurants. Main dictionary is expanded_broad_pre; no dictionary retuning. The report explains historical windows, missing-history handling, spatial cell construction and raw p-value symbols.
